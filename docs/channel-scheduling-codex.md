# 智矩 AI 频道排期

入口：频道排期 → 选择频道 → AI 排期。选择频道当地起止日期、每日更新数量和每档所需题材，生成预览后确认保存。

## 数据与判断

- 正式候选以 `production_completion_status=completed` 为准，上游节点未回填不再阻挡；停用、过期、不制作和禁用剧排除。
- 频道语言必须出现在智核正式 `finished_languages` 成片清单中。NULL 是未同步，空数组是没有完成语言，均不猜测可用。
- 使用已生效的频道资料；无正式分析时可用冷启动定位和生成规范。已生成但未应用的分析不改变本次依据。
- 同频道读取完整系统排期历史去重；跨频道可以用同剧。已有日期档位全部保留，包括取消后的历史行。仍需改动旧行时使用现有人工入口。
- 按本次日更数量读取“频道档期表”的统一档期模板，当地时间按频道 IANA 时区换算。模板未配置完整时提示补齐模板；旧的频道独立档位不再作为配置来源。
- AI 分批阅读全部候选的真实剧情，保留适配判断和原文引用，再结合紧凑判断编排每天组合。事实明细留在冻结快照，模型只读所需频道文档；不将全部视频历史塞进提示。
- 选择排期 Skill 修订 2 时，从当前生效的分析诊断冻结 `content_priority`（主题材）和 `content_secondary`（辅题材）。新频道使用已应用的初步分析。每档依照用户选择的类别，入选须引用该类别的报告方向及真实核心剧情。没有合格方向或候选时按档留空。同一天允许按各档选择不同方向。
- 主档不少于100分钟并优先较长者；已知不足30分钟的剧不进入候选。辅档时长未知会展示提示。旧规划保留当时的输入和 Skill。

## 预览与确认

规划使用独立 `channel_schedule_plans` 任务，不产生运营包工单。快照固定频道资料、Skill、模型、剧库、档位和排期目标。预览展示当地日期、北京时间、剧名、时长、真实剧情依据及配对理由。

点击确认后，在同一事务中重查候选、到期、频道语言、历史和统一档期模板。模板或频道时区变化时要求重新规划。保存排期时关联相同时间定义的历史档位；缺少对应定义时才新增冻结记录，不启用或改写旧档位。任一冲突则不写入本批排期；允许有明确缺口的计划只保存可用行。重复确认返回已保存结果。保存本身不上传、发布或启动运营包。

新排期固定频道资料版本；后续运营包使用该版生成规范，其他固定生产资产继续沿用原配置。历史自由文本“运营参考”保持原有用途，不能当七段生成规范覆盖已有生产配置。

## 执行与恢复

本机沿用已有执行授权，任务类型 `channel_scheduling`。云端领取、心跳、结果回传与取消均校验公司及执行主机。超过150秒无心跳显示连接待确认，不据此认定进程停止。

成功的剧情评估保存在本机运行目录，回传前先落盘。失败后先确认旧进程停止，再恢复同一任务；保留已完成评估，新的领取重新规划失败部分，不反复复用失败结果。候选或频道资料需要更新时取消并建立新规划。

Skills → 频道排期支持查看、上传、发布和指定默认版本；旧任务继续使用冻结版本。
