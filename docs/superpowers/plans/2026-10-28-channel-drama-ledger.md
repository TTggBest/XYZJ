# 频道剧目台账实施计划

目标：频道列表直接进入独立整页，以智矩现有已同步、制作完成的剧目为底表，关联全部上传记录和有效排期，帮助操作者发现未上传剧目与重复使用。用户已明确当前为157部，不依赖重新访问智核或备份。

范围：不增加一级菜单、不阻止重复上传、不修改排期、不触发制作；不合并或部署。复用现有 FastAPI、TenantSession、原生 JS 和同步入口，无新增依赖。

## 已确认设计

六列：剧名（剧库主名）、我们的ID（DRM）、剧ID（videoId）、公开范围、上传日期、排期。公开范围为公开/私享/未列出/预约时间/未上传的横线。排期为已公开绿色对钩、有效排期时间或横线。失败记录整行浅红并标明失败，不冒充未上传。每次上传独立一行，同剧按内部ID相邻；可靠关联的排期合到对应视频行，其他有效排期独立保留。

入口方案：不增一级菜单；不放详情抽屉；采用频道列表按钮进入独立二级整页，详情提供同入口。页内切换频道、搜索、公开范围/是否排期筛选、排序、同步与最近同步时间，返回保留频道筛选。

## 数据边界

初版错误地使用剧级完成状态与语言素材状态的交集，后续又错误地引入新智核逐语言清单依赖，均造成现有完成剧被漏掉。最终口径按用户确认：仅使用智矩已保存的 `production_completion_status=completed` 且有效的剧目为底表；语言/素材/新增finished_languages字段不阻断台账，不推断具体语言文件存在。

上传/排期历史不受库存条件限制。未可靠识别剧目的视频单列待匹配，不按近似标题强绑。取消/替换排期不算当前排期。无完整同步提示数据未完整，不将空记录包装为已确认从未上传。
