# 智矩剧库第二阶段：制剧进度与语言覆盖设计

日期：2026-08-28

## 目标

在一期剧库主档基础上增加两套彼此独立的数据：

1. 每部剧唯一一套制剧进度，记录网盘下载、统一参数、字幕提取、鬼手上传、角色提取和制作完成。
2. 每部剧已经完成哪些目标语言，用于展示语言覆盖数量和明细。

本阶段先支持智矩人工维护和飞书语言表同步。智核进度通过正式 API 接入，不直接读写智核数据库，也不在接口尚未确定时伪造同步结果。

## 已确认事实

- 制剧进度与语言无关，一部剧只有一套制剧进度。
- `drama_translations` 已经表示剧目和语言的覆盖关系，不能复用为制剧进度。
- 飞书“语言”页实际 Sheet ID 为 `OHTcqg`，第一行是 S/A/B/C 优先级，第二行是语言名称，第三行起是剧目数据。
- 飞书当前共有 21 种语言，不是 20 种：印地语、孟加拉语、印度尼西亚语、菲律宾语、西班牙语、巴西葡萄牙语、土耳其语、阿拉伯语、英语、俄语、泰语、越南语、法语、马来语、德语、乌尔都语、意大利语、韩语、日语、波兰语、希腊语。
- 飞书语言单元格值 `1` 表示该剧已经制作该语言；空白表示尚未制作。
- MySQL 是智矩业务事实来源。飞书仍是过渡期语言覆盖数据的上游来源。

## 数据模型

### `drama_production_states`

每部剧最多一条记录，以 `drama_id` 唯一约束，不包含 `language_id`。

字段：

- `drama_id`：剧目内部 ID。
- `cloud_download_status`：网盘下载。
- `parameter_normalization_status`：统一参数。
- `subtitle_extraction_status`：字幕提取。
- `guishou_upload_status`：鬼手上传。
- `role_extraction_status`：角色提取。
- `production_completion_status`：制作完成。
- `episode_count`：剧集数，可空。
- `total_duration_seconds`：剧集合集时长秒数，可空。
- `source_type`：`manual` 或 `zhihe`。
- `source_external_id`：智核剧目 ID，可空。
- `source_updated_at`：智核数据更新时间，可空。
- `source_synced_at`：智矩最近同步时间，可空。
- `last_error`：最近同步或节点失败原因，可空。

六个节点状态固定为：

- `not_started`
- `in_progress`
- `completed`
- `failed`

当前节点和整体进度由六个状态按固定顺序计算，不重复落库。修改时写现有 `AuditEvent`，本阶段不新增通用工作流框架或独立历史表。

### 复用 `drama_translations`

- 飞书语言单元格为 `1` 时，确保存在对应 `DramaTranslation`，并设为 `translation_status='ready'`、`asset_status='ready'`。
- 单元格为空时，不创建新记录；如果该关系先前由飞书创建，后续同步为空则删除该飞书覆盖关系。
- 为区分人工和飞书维护，增加 `source_type`：`manual` 或 `feishu`，以及 `source_synced_at`。
- 飞书同步只覆盖 `source_type='feishu'` 的关系，不删除人工维护的语言覆盖。
- 剧名只按规范化中文主剧名精确匹配。飞书存在但智矩剧库不存在的剧目记为冲突并回滚，不自动新建主档。

## API

新增接口：

- `GET /api/v3/drama-production`：分页列出剧目及六节点状态，支持剧名、批次、整体状态和当前节点筛选。
- `GET /api/v3/dramas/{drama_id}/production-state`：读取一部剧的制剧进度。
- `PUT /api/v3/dramas/{drama_id}/production-state`：人工更新六节点、剧集数和总时长。
- `POST /api/v3/feishu-sync/drama-languages`：按实时标题解析“语言”页并增量同步 21 种语言覆盖。
- `PUT /api/v3/dramas/{drama_id}/languages/{language_id}`：人工新增或更新语言覆盖。
- `DELETE /api/v3/dramas/{drama_id}/languages/{language_id}`：删除人工维护的语言覆盖；不删除语言定义。

既有剧库详情接口扩展 `production_state`，继续返回 `languages` 和 `channels`。

## 页面

### 制剧进度表

剧库页面增加“制剧进度”入口。表格每部剧一行，固定展示：序号、剧名/剧库编号、批次、六个节点、整体进度、最后更新和详情入口。

- 状态用明确文字和颜色区分，不仅依赖颜色。
- 顶部支持搜索、批次、整体状态和当前节点筛选。
- 表格中的节点不做循环点击切换，避免误操作；编辑在详情抽屉中完成。
- 更新后局部刷新当前行并保持页面滚动位置。

### 剧目详情

详情增加“制剧进度”标签：

- 展示六节点状态、剧集数、合集时长、数据来源和最近同步时间。
- 代码机可人工编辑状态。
- 智核数据接入后，仍允许人工补充，但下一次智核同步会覆盖智核管理字段，页面明确提示来源。

语言覆盖标签增加：

- S/A/B/C 分组展示 21 种语言。
- 已完成和未完成状态明确区分。
- 支持人工增加或移除覆盖。
- 顶部提供“同步飞书语言”按钮。

## 飞书语言同步

1. 每次按 Sheet 标题“语言”解析实时 Sheet ID。
2. 读取前两行：第一行映射优先级，第二行映射语言名称，不使用普通单表头解析器。
3. 完整校验 21 个语言列、重复剧名和未知语言后再写库。
4. 同步语言定义，再按规范化中文剧名更新语言覆盖。
5. 完全一致计为跳过；新增、删除和冲突分别计数。
6. 整次事务失败回滚，并写 `FeishuSyncRun(sync_type='drama_languages')`。

## 智核接口边界

本阶段输出独立需求文档，要求智核至少提供：

- 稳定智核剧目 ID、中文剧名和最后更新时间。
- 剧集数、合集总时长。
- 六个节点的状态、开始时间、完成时间和失败原因。
- 统一参数视频、字幕、鬼手任务和角色提取结果的资源定位地址。
- 按更新时间游标分页拉取变化数据的接口。
- 按单个智核剧目 ID 查询完整状态的接口。

智矩后续通过服务接口主动补同步，并可接收智核完成事件通知。两边都不直接修改对方数据库。正式字段与认证方式由智核确认后再实现适配器。

## 错误处理

- 制剧节点状态不合法：返回 422。
- 剧目不存在：返回 404。
- 后置节点完成但前置节点未完成：拒绝保存，返回明确节点原因。
- 制作完成时，前五个节点必须全部完成。
- 飞书第二行存在未知语言或缺少既定语言：整次语言同步失败并列出列号。
- 飞书语言页存在重复剧名、空剧名或剧目未入主库：整次同步失败并列出源行号。
- 人工语言覆盖和飞书覆盖冲突：保留人工记录，不由飞书删除。

## 测试与验收

- 模型和迁移测试：唯一剧目进度、六节点状态约束、语言优先级和语言来源字段。
- 服务测试：进度计算、节点顺序校验、人工更新、语言增加/移除。
- 飞书测试：双表头解析、21 种语言映射、新增、删除、跳过、冲突和事务回滚。
- API 测试：分页筛选、详情、更新和错误响应。
- 前端契约测试：制剧进度入口、六节点表格、详情标签、语言分组和同步按钮。
- 开发 MySQL 验收：执行迁移、同步飞书语言页、重复同步验证幂等、核对剧目总数不变。
- 不写生产数据库，不合并 `dev`，不打包生产运行包。

## 本阶段不做

- 不实现未经智核确认的真实智核调用。
- 不把制剧进度拆成按语言记录。
- 不自动下载网盘、调用智核、鬼手或角色提取服务。
- 不物理删除剧目、语言定义或历史运营数据。
- 不做频道自动下架、YouTube 自动上传或排期生产。
