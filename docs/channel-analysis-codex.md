# 智矩频道分析与 Codex

入口：频道详情 → 分析中心 → 开始分析。

频道分析使用系统已绑定的主机、Codex 账号和模型，但拥有独立任务和记录，不创建单剧工单或运营包。

## 正式分析

选择正式分析后，先用当前频道已有授权核验 YouTube 身份和 Analytics 读取范围，授权失效时重新授权。成功建立草稿后，上传一个近期完整28天的 Studio 内容导出 ZIP，以及视频页和观众页截图。帖子未使用、没有已完成的 A/B 测试时可明确勾选不适用，否则需上传对应截图。

平台要求 ZIP 日期覆盖连续28个不同日期，重复行不能补足缺失天数。API 以 Studio 的实际完整截止日对齐28/90天趋势、视频、地区、流量、设备及视频资料；截止日不得在未来，且距最近完整日不超过7天。上传视频清单通过 uploads 播放列表分页取得；Analytics 视频样本另行标注口径，不把 Top200 当作全部上传视频；API 失败项保留不可用原因。相同频道和窗口的已成功数据可复用，恢复不重复采集成功项。截图通过实际图片附件交给 Codex，身份、页面与窗口不能只相信上传名称。

## 冷启动

点击“新频道冷启动”，使用 channel-initial-audience；初始定位可从用户输入和已登记资料取得。已有实测分析或非零运营指标的频道需走正式分析，只有公开视频元数据不代表已有实测画像。冷启动不要求上传不存在的 Studio 数据，也不请求 Google API；报告须标明“冷启动”和“未经数据验证”。

## 结果与应用

分析完成后为待应用，页面可查看/下载三份 Markdown 及 JSON 快照。点击“应用此版本”后，报告、画像和运营参考入库，生产配置使用新七段规范并记录分析版本；已有固定资产、播放列表、专属标签白名单和既有生产快照不覆盖。生成 HASHTAG 规则不会自动补出缺失的专属白名单。

频道资料、原始材料、历史报告、事实快照及生产版本以服务器为准。执行器不读取本机频道注册表、定位文件或频道文件夹，也不把报告写入本地频道根目录。Codex CLI 在临时执行目录中生成结果并回传服务器；收到服务器保存确认后删除本次任务的材料、输出和断点文件。断网未确认时仅保留待重传数据，下次唤起先重传；失败任务的可复用文档断点随失败记录保存在云端，换电脑重试从云端恢复。页面只显示云端状态，不再提供“同步本地文件”。

其他电脑完成现有主机绑定和 Codex CLI 登录后即可作为执行端，无需复制原电脑的频道目录。应用版本仅切换云端生产配置，查看与下载历史结果均从云端读取。

正式分析的事实 JSON 由程序根据 API/Studio 计算并冻结，模型仅生成分析文档和截图核对结果。逐内容 CTR 与加权 CTR 保留来源/口径；集中度无法计算时明确不可用。截图中的受众细分和 A/B 等供视觉分析，未经程序核实的数值在事实 JSON 中保持 unavailable。模型输入只带规则一次、归一事实和重点队列剧情；原始响应、完整 CSV 和全部映射保留归档。

## 本机组件更新

部署后，本机执行器也需要使用包含本次功能的版本。已有登录、授权和唤起机制沿用；新增 channel_analysis 固定任务类型，不另建认证系统。


每次历史目录均包含日期与运行 ID，保留 API 原始数据、原始 ZIP、截图、JSON、更新前文件和最终快照。授权令牌不进入模型提示词或归档。

本次数据库变更是新表 `channel_analysis_runs`，Alembic 版本 `e94a1c729b30`。不能仅更新前端后宣称上线；需按现有发布流程完成云端迁移、服务发布和本机组件更新。

## 开发验证边界

自动测试使用隔离 SQLite、模拟 Google 数据和假的 Codex CLI；验证生命周期、结果校验、断点恢复、租户隔离、HTTP 入口、图片参数与原执行器行为。未将测试通过表述为已完成真实 Google/Studio 截图分析，也未自动调用真实模型。

## 授权失效与恢复

频道列表“授权”列读取当前执行器实际选用的最近验证授权状态，不以历史绑定数量判断。令牌不存在、缺少刷新令牌或 Google 明确返回授权失效时，保存 expired；网络、配额及 OAuth 客户端配置错误不会因此把授权标为失效。读取列表本身不调用 Google。

失效频道显示“需重新授权”，可点击该标记、顶部提示或右侧“…”菜单中的“重新授权”。云端沿用现有 `/channels/{channel_id}/youtube-authorization/start` 和回调，验证精确频道后恢复授权；频道生命周期“已接入”与当前 API 授权分开显示。
