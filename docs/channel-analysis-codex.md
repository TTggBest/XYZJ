# 智矩频道分析与 Codex

入口：频道详情 → 分析中心 → 开始分析。

频道分析使用系统已绑定的主机、Codex 账号和模型，但拥有独立任务和记录，不创建单剧工单或运营包。

## 正式分析

选择正式分析后，先用当前频道已有授权核验 YouTube 身份和 Analytics 读取范围，授权失效时重新授权。成功建立草稿后，上传一个近期完整28天的 Studio 内容导出 ZIP，以及视频页和观众页截图。帖子未使用、没有已完成的 A/B 测试时可明确勾选不适用，否则需上传对应截图。

平台验证原生 CSV 与实际日期区间，API 采集28/90天趋势、视频、地区、流量、设备及视频资料。视频数量使用分页，不把前200条当全量；API 失败项保留不可用原因。相同频道和窗口的已成功数据可复用，恢复不重复采集成功项。截图通过实际图片附件交给 Codex，身份、页面与窗口不能只相信上传名称。

## 冷启动

选择冷启动并填写初始定位。已经有公开视频或非零运营数据的频道需走正式分析。冷启动不要求上传不存在的 Studio 数据，也不请求 Google API；报告须标明“冷启动”和“未经数据验证”。

## 结果与应用

分析完成后为待应用，页面可查看/下载三份 Markdown 及 JSON 快照。点击“应用此版本”后，报告、画像和运营参考入库，生产配置使用新七段规范并记录分析版本；已有固定资产、播放列表、专属标签白名单和既有生产快照不覆盖。生成 HASHTAG 规则不会自动补出缺失的专属白名单。

本地三份当前文件只在应用后更新。生效前仅写历史；旧生效任务标记 superseded，后续唤起不会把旧规范覆盖回当前文件。云端应用和本地镜像分别显示完成情况，镜像失败可重新唤起，不调用模型。

## 本机组件更新

部署后，本机执行器也需要使用包含本次功能的版本。已有登录、授权和唤起机制沿用；新增 channel_analysis 固定任务类型，不另建认证系统。

安装脚本新增 `--analysis-workspace-root /绝对路径/项目根目录`，用于找到 `运营/工作流运营/公用/频道注册表.json` 及频道目录。注册表未包含的新频道，可通过已有 `频道初始定位.md` 中的频道 ID 定位。未设置根目录时使用 `~/Documents/智矩频道分析/频道分析/<语言>/<频道名>/`，不是原项目目录。

每次历史目录均包含日期与运行 ID，保留 API 原始数据、原始 ZIP、截图、JSON、更新前文件和最终快照。授权令牌不进入模型提示词或归档。

本次数据库变更是新表 `channel_analysis_runs`，Alembic 版本 `e94a1c729b30`。不能仅更新前端后宣称上线；需按现有发布流程完成云端迁移、服务发布和本机组件更新。
