# 频道低播放剧目清理

用户已批准开发，并明确更正比较范围：点击频道功能时重新拉取 API 播放数据，以整个频道所有已公开长剧的累计播放量中位数为正常水平。仅判断公开满 5 天的视频，低于该频道正常水平的 20% 才可删除。删除 YouTube 视频成功后清理这次发布的排期、工单、运营包及视频关联，剧库原始资料和其他频道保留。

## 实现口径

- 复用频道 OAuth 和上传视频列表读取，增加可选 statistics。只获取 Data API 当前数据，不引入 Analytics 逐日采集。
- 删除资格为公开满 5 × 24 小时，按实际公开时间计算。基准包含全频道所有已公开长剧（至少 30 分钟）的有效当前播放量，包括上线不足 5 天、很早上线和未关联本地剧库的长剧。缺失播放量、未公开、已删除、短视频不参与基准；频道样本至少 5 个。不再按上线天数划分比较窗口，不限制最多 20 个样本。
- 所有候选使用同一个频道基准和删除线，页面直接显示参与计算的全频道剧目数量、中位数和删除线。未关联剧库的剧目只参与基准计算，保留原有不可自动删除的规则。
- `当前播放量 < 同类样本播放中位数 × 0.2` 命中，恰好等于门槛时保留。无播放量、非公开视频、未关联剧库、发布时间缺失等按明确原因跳过。
- 在频道“更多”及频道排期提供入口。读取后展示视频、播放量、上线天数、基准和删除线。一次确认整个清单。执行时重新获取当前数据，已不符合条件的跳过。
- 按视频确定发布关联范围。生产任务正在执行、关联指向不同视频或其他频道时跳过，避免清理错误记录。
- 删除前保存操作记录，YouTube 返回成功后保存视频删除状态，再在本地事务清理关联。局部失败逐项返回，保留已成功结果。若响应超时或保存删除状态失败，下次按原视频 ID 通过 API 确认不存在后继续本地清理。
- 复用既有审计表保留判断、频道/剧目/视频、删除时间及清理结果。保留原始媒体文件，清除运营包关联和交付记录。无新增表或数据库迁移。

## 定向验证

用隔离 SQLite 数据和模拟 Google API，验证新鲜数据、5 天边界、频道与上线时长比较、缺失数据、删除失败保留关联、成功清理后重新进入排期候选、其他频道保持、局部失败续清理。前端通过现有 DOM harness 走读取清单到确认执行，验证发送的频道和视频及执行后展示。

本次授权为开发。提交候选、合并、部署、真实视频删除分别报告，开发测试不执行线上删除。

- 新功能的隔离服务、权限、租户范围和前端 DOM 操作测试 21 项通过。

- 尚未合并、部署或删除真实视频，线上与视觉验收留待发布后的实际入口核对。

## 全频道基准更正

- 用户明确比较范围为整个频道所有已上线剧目，取消相近天数窗口和 20 个样本上限。5 天只限制删除资格。
- 24 项隔离测试通过，覆盖新旧公开视频共同参与基准、31 个样本全部计入、未绑定视频参与基准但不删除、私享及短视频不参与，以及原有删除失败与恢复行为。
- 页面增加全频道参与数量、正常播放中位数、删除线。原“跳过”改为“本次不删除”，避免把删除资格与基准参与范围混淆。
