# XY Cover

## Purpose

This step only does one thing:

- generate covers from the 3 approved titles

It does not search plot, does not generate titles, and does not write community or description content.
Workflow position:

- run this only after `xy-title` is finished and the user explicitly asks for cover output
- this step must stay aligned with the same result groups from `xy-find` and the same title groups from `xy-title`
- do not run `xy-merge` before this step is finished

## Inputs

Read:

04_标题方案.md
01_搜索资料.md
频道名_生成规范.md

## Rules

- Before generating anything, check whether `01_频道数据.md` exists in the current package folder. If it does not exist, invoke `xy-data` first and create it.
- `频道名_生成规范.md` is a channel-level dependency. It must come from the corresponding channel folder and is not generated by this workflow.
- Output one cover-result block per title-result block from `04_标题方案.md`.
- Do not force exactly 1 cover-result block.
- Each cover-result block must contain 3 cover groups, one for each title in that result block.
- Each title must have one `4:5` cover and one `16:9` cover.
- The `4:5` cover is text-to-image.
- The `4:5` size must be fixed at `1728x2160`.
- The `16:9` cover is not text-to-image.
- The `16:9` cover must be image-to-image expansion from the approved `4:5` image.
- The final `16:9` size must be fixed at `3840x2160`.
- All image prompt descriptions must be written in English.
- Strictly forbidden semantic concepts in every generated cover-owned field: rape; sexual assault; molestation; drugged; date rape or drugging; sold a person; human trafficking; kill; murder; shooting or killing; suicide; self-harm; corpse or dead body; bloody or gory; torture; poisoning to death; brutal killing. Translation, inflection, euphemistic spelling, or visual implication does not make the concept usable.
- Prefer not to use these semantic concepts; create another title-linked conflict expression whenever possible: domestic violence; abuse; kidnapping; death threat.
- Apply this blacklist while creating the cover plan and prompt. Do not rely on a downstream Validator or cleaning pass.
- Scene, characters, action, composition, lighting, style, safety, and `16:9` outpainting instructions must all be described in English.
- Do not write Chinese scene descriptions inside the actual `4:5` or `16:9` prompts.
- Never put `16:9`, outpaint, locked-center, side-band, wide-canvas, pixel-restoration, or any other wide-image execution wording inside `scene_prompt_4_5`. The portrait scene field must describe only the `4:5` cover; wide execution is owned by the controller's separate downstream task.
- Only the visible cover text / core words may use the channel language.
- Chinese is allowed only in labels, explanations, review notes, or output field names outside the actual prompt text.
- The `4:5` cover must contain the cover core words.
- Cover text must be exactly 1 or 2 independent words only; never use a multi-word phrase, sentence, or several core-word combinations.
- The visible cover text must be short, explicit, and immediately readable.
- Render the exact core words as visually prominent, highly legible, high-contrast, non-diegetic editorial cover typography floating over suitable negative space above the photographed scene. They are a title layer, not an object inside the story world.
- Use a `typography_salience_rule`, never a fixed size rule. Do not prescribe any fixed width, height, font size, or canvas ratio. Adapt font size, line breaks, color contrast, outline, compact hard shadow, optional restrained backing shape, and placement to the language, core-word length, available negative space, local background brightness and color, and actor placement. Prominent does not mean largest possible: human faces and the dramatic event remain the primary visual storytelling elements. Keep the typography clear of primary faces, critical hands, essential story objects, and channel logos.
- Keep the complete typography inside the centered 1728x2160 `4:5` image area. It must never extend into the left or right outpaint bands of the final `3840x2160` image.
- The core words must never be printed, painted, written, engraved, projected, reflected, displayed, or attached on a wall, door, paper, document, folder, book, screen, clothing, sign, or physical prop.
- Natural incidental Chinese environmental text on signs, documents, boards, buildings, or props is allowed, but it must never carry or substitute for the core words.
- Phrases with 3 or more words are invalid for cover text.
- When outputting each cover group, always provide the exact matching `核心词`.
- The three groups must use three different core-word values. Normalization, capitalization, or whitespace changes do not make a repeated value unique.
- The `16:9` version must not change the center content of the approved `4:5` image.
- First scale the approved `4:5` image proportionally to `1728x2160`, then center it on a `3840x2160` canvas.
- The middle `1728x2160` area is an absolute locked zone.
- Inside the locked center zone, do not change any character, prop, lighting, sharpness, text, or composition.
- The left and right sides are `1056px` each and may only be used for environmental outpainting.
- Do not reconstruct the image.
- Do not rearrange the composition.
- Do not resize, move, rewrite, restyle, recolor, re-outline, re-shadow, reflow, or reposition any text from the approved `4:5` image.
- The center content and text position must remain exactly the same as the approved `4:5` image.
- Preserve the non-diegetic core-word typography in exactly the same position, scale, and style during the `16:9` expansion.
- In the final `16:9` image, preserve the approved core-word typography exactly inside the locked centered `1728x2160` area; do not apply any new size or ratio requirement.
- The `16:9` version may only extend left and right. Do not alter the center.
- Before writing any `scene_prompt_4_5`, commit in this order: `visual_payoff`; `required_characters` and visible adult/child counts; fresh scene; fresh action; optional supporting prop; standard `camera_angle`; core-word category and reason; then the prompt.
- Every 4:5 group must contain exactly one continuous moment in one physical location with one coherent lighting environment. Set `single_continuous_moment=true`, `single_physical_location=true`, and `temporal_montage=false`.
- The A+B title does not authorize two illustrated beats. Choose only the strongest single visible instant. If upstream `visual_thesis` names more than one moment, distill it into one `visual_payoff`; never reproduce both.
- Never use split screen, vertically stacked scenes, collage, diptych, multi-panel layouts, before/after, present/later, cause/result pairing, temporal montage, or an adjacent second moment.
- For a group with no required child, plan 2 to 4 visible adults and no extra people. The final scene may contain only `required_characters`, with no background crowd, assistants, guards, shareholders, relatives, or readable extra faces.
- Never depict Chinese police, public-security, traffic-police, special-police, law-enforcement, or other public-service uniforms in a cover. Police caps, police badges, police emblems, police epaulettes, police shoulder boards, police service numbers, and police-style uniforms are forbidden. If the plot needs an order-maintaining figure, use only a commercial security guard in a plain neutral security uniform with no government or police insignia.
- Keep every required child and remove optional adults first. Use this priority: required child anchor > protagonist > primary antagonist/lover > optional adults.
- `visual_payoff` must state the strongest emotional power shift, relationship reversal, or visible consequence. Do not convert title nouns directly into props; `key_prop` is optional supporting evidence and never the sole visual B explosion.
- `scene_family`, `scene`, `main_action`, `composition`, and optional `key_prop` are fresh free creative text for the current title. Do not choose any of them from a reusable scene, action, composition, prop, or reaction candidate list.
- If a location detail does not improve story comprehension, emotional intensity, or visual realism, omit it. Do not invent decorative architecture, luxury dressing, lighting spectacle, or art-direction detail merely to sound professional.
- Use half-body framing by default so the image reads clearly on mobile.
- Main characters should be as large and readable as possible.
- Every visible person must be depicted as a Chinese person with clearly Chinese facial features and appearance, regardless of the target channel language or market. Do not use Indian, Southeast Asian, Middle Eastern, Western, or ambiguous facial features.
- Every actual image prompt must explicitly include: `Chinese actors, Chinese facial features, East Asian appearance`.
- The image must have strong conflict, be eye-catching, have a clear explosive point, and improve click-through.
- The image must clearly reflect the title content.
- Do not use doors or vehicle doors as primary scene devices. Never build the scene, main action, actor interaction, or camera blocking around opening or closing a door, blocking, standing, waiting, or leaning at a doorway, entering or exiting through a vehicle door, gripping a car door, or confronting across a door. Freely create a fresh title-specific non-door scene and action without selecting from a replacement list. A distant closed door may remain incidental background architecture only when nobody interacts with it. This is a hard generation and validation requirement.
- The visible text on the image must be prominent and easy to notice.
- The 3 cover groups must not share the same main action.
- The 3 cover groups must not share the same scene.
- The 3 cover groups must not share the same environment.
- Every localized core-word hook must be one idiomatic native-language word or a natural two-word modifier-plus-head phrase. Never join two plot nouns mechanically or omit a linker, postposition, case marker, or article just to force a longer natural phrase into the two-word limit. Choose another one- or two-word hook instead.
- Before writing prompts, return a visual blueprint for every group with `story_hook`, `scene_family`, `scene`, `main_action`, `key_prop`, `composition`, `palette`, and `lighting`.
- `scene_family`, `main_action`, `key_prop`, `composition`, `palette`, and `lighting` must each be different across all 3 groups. Changing only clothes, a document label, or camera crop does not count as a different group.
- Read `visual_history` and same-drama `creative_history` when the controller provides them. Partial reuse of channel-level visual grammar is allowed across videos: character count, shot size, camera angle, placement logic, typography-layout logic, or scene type may each be similar.
- A single similar visual dimension is not narrative duplication. Do not force a different composition solely to avoid resemblance to a recent cover.
- Do not reproduce the whole visual combination as a template. For the current title, reorganize the overall scene, action, relationship, and composition instead of repeatedly combining the same character count, shot size, camera angle, placement, scene type, and typography layout.
- Reject only a substantially duplicated complete narrative concept: a highly similar combination of character relationship, primary action or reversal, key event or evidence prop, and core cover words. When several key visual dimensions and that narrative concept are both highly similar, actively separate the new design.
- Do not use a numeric similarity ratio or fingerprint-count quota for generation. Same channel style is allowed; the same template or complete visual story is not. A different language alone does not make a duplicated complete narrative concept new.
- Treat the title `packaging_brief` as binding. Return its exact `creative_slot_id` as `packaging_brief_id`, and copy its `channel_direction` and `core_story_promise` exactly; the controller rejects any drift before writeback.
- Choose the visual blueprint from a plot-specific physical event. Do not default to `luxury mansion + standing confrontation + document/phone + dark brown/red/gold light`.
- Each group must independently create a different title-specific conflict moment. Do not select the conflict, scene, action, or reaction from an enumerated answer list.
- `camera_angle` must be exactly one of `eye-level`, `slightly low-angle`, `slightly high-angle`, `over-the-shoulder`, or `three-quarter view`; these are technical values, not composition templates.
- Select core words by priority: specific relationship > shocking identity > concrete number > concrete consequence > abnormal action > abstract theme. Use `abstract_theme` only when no concise package-specific phrase is available. Never select core words from a reusable multilingual candidate library.
- Prompts must describe photographic spatial logic: who is where, who acts on whom, what physical evidence proves the hook, and what background reaction or environment confirms the location.
- Use a natural live-action TV drama still with realistic lens rendering, natural Chinese skin texture, ordinary clothing wrinkles, believable location lighting, and slightly softer environmental detail. Keep faces readable through framing and real light, not through artificial sharpening.
- Do not use `ultra sharp focus`, `crisp facial detail`, `crisp faces`, `strong/high micro-contrast`, `clean edges`, `sharp facial highlights`, or `mobile readability` as image-rendering instructions.
- Vary time of day, color temperature, dominant hue, light direction, and environmental materials. Do not make every cover dark, amber, red, brown, gold, smoky, glossy, or mansion-like.
- Avoid waxy skin, plastic beauty-filter faces, generic AI glamour, muddy shadows, orange/brown color casts, heavy haze, excessive bokeh, empty luxury decoration, and motionless poster posing.
- For male-frequency dramas, if the drama involves costume, fantasy, cultivation, time-travel, or similar themes, visual effects should be visible.
- If children are present, never show child humiliation, child abuse, or similar harmful scenes.
- Children must always be fully clothed, safe, healthy, and supervised. Never depict a verified minor as crying in distress, injured, restrained, threatened, kidnapped, sick, unconscious, endangered, isolated, or within the actual danger range of weapons, fire, explosions, blood, harmful medical procedures, or adult physical violence.
- When a required minor is visible, do not combine that minor in the same image prompt with abandonment or humiliation directed at the child, hidden surveillance, coercive parenting, bedroom or bedside intimacy, police restraint/escort/control, paternity-evidence confrontation, or adult physical/coercive conflict. Express the click-driving reversal through adult status, posture, relationship, or consequence while the child stays calm, protected, and clearly supervised. Keep every required child and do not replace the title-linked event with unrelated generic family activity.
- `daughter`, `son`, `girl`, or `boy` alone does not establish minor status. Prefer structured age and role facts; explicitly adult offspring are excluded from child checks. Adult fear, humiliation, tears, injury, or conflict must not be attributed to a nearby safe child merely because the words occur in the same sentence.
- Resolve child presence independently from each accepted Find/title direction. Channel direction and drama name never force all three groups to add a child. A direction whose only child fact is not yet born does not require a visible born child. For every direction that actually contains a born minor, `child_role` is binding while `safe_cover_scene` is reference-only; the title's `visual_thesis` remains the scene priority.
- The controller repeats the exact per-group upstream title, title translation, visual thesis, and child role at the end of the initial generation prompt and every retry. It may include the safe child scene only as a reference. Correcting typography, realism, or collision must never remove a mandatory visible child or regress another passing hard rule.
- Every retry keeps the same compact all-group checklist: exact upstream mapping, concise base prompt, no physical or threatened violence, non-diegetic core typography, distinct core words, and zero visual special effects for female-frequency tasks.
- Covers must not be overly violent or bloody.
- Covers must not contain sexual content.
- The final result must avoid triggering child/youth depiction violations.

## Output File

This step returns structured cover-planning data only. It does not generate images, write files, update workflow state, or call an image-generation tool. The controller owns all file rendering, state changes, and final prompt assembly.

For each title, return only the scene-level `scene_prompt_4_5` and the environment-only `outpaint_environment` together with the required identity, mapping, core-word, and visual-blueprint fields. Do not construct or return final `prompt_4_5` or `prompt_16_9`; the controller creates both after Schema acceptance.

Each result object in JSON must carry both:

- `result_id`: the unique per-result-group ID such as `Qe7OMYCtRQk_1`
