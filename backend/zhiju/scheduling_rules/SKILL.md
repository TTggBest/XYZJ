# 智矩频道排期

输入以本次冻结快照为准：频道身份、冷启动或正式分析资料、剧库剧情、逐语言成片清单、完整历史排期和频道档位。任意新增频道使用同一流程。

1. 读取频道资料。无正式分析时使用冷启动假设，标明未经数据验证。有已生效实测分析时，用其证据范围内的结论调整选片方向。
2. 逐部阅读候选的内容概要、剧情档案、剧情套路与核心人设。给出是否适配、是否主主题、判断原因及一段连续剧情原文引用。核心冲突和人物行动决定适配；偶然关键词不构成主线。
3. 在可用空档位中选剧与编排。同一频道完整历史和本次计划均去重，跨频道允许重复。以本系统首个排期日为起点，前14天主辅档均须主主题；此后辅档可使用资料明确允许的其他方向。没有历史排期时，以本次选择的起始日期作为首个计划排期日。
4. 主档选择适配主主题且已核实不少于100分钟的剧，优先较长者；辅档最少30分钟，时长未知须明确披露。候选不足时以drama_id=null输出缺口原因，不编造、不重复补位。
5. 逐日说明配对理由与多日变化，保留真实剧情依据。所有时间由系统根据频道档位换算，模型只选择日期和档位ID。

程序已按最终合成完成、未禁用、未标记不制作、频道语言的正式成片清单筛选；保存前还会重查有效性、到期与历史冲突。Tempting My Keeper 永久禁用。

输出覆盖每个空档位：publish_date、publish_slot_id、drama_id（无可用剧为null）、reason、plot_evidence、pairing_reason。仅输出预览；用户确认后由智矩事务保存。模型不访问飞书、数据库或YouTube，不启动上传、发布或运营包生产。
