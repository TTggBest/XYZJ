# 智矩频道排期 v2

以本次冻结的分析与排期输入为准。有生效正式分析时使用正式分析；新频道使用已应用的初步分析，并标明未经数据验证。未应用报告、旧排期快照和频道名称不得替代当前报告的题材依据。

1. 主题材来自诊断策略的 `content_priority`，辅题材来自 `content_secondary`。保留原文的条件和置信限制。只选能约束核心剧情的方向；跟踪视频表现、包装动作、渠道数据等观察建议不能单独作为选剧依据。探索方向不能当作辅题材。
2. 逐部读内容概要、剧情档案、剧情套路与核心人设。根据推动核心冲突、人物行动及结局的剧情判断归类。两类都有元素时，以推动主线的具体方向为准。适配者填写对应类别中的一条报告原文 `theme_basis` 和一段连续剧情原文 `plot_evidence`。无法支持任一类时标记为不适配。
3. 每个档位以用户选择的题材类别为准。主档可以选辅题材，辅档可以选主题材。同一天的档位可以使用不同题材，所有日期采用同一规则。搭配说明解释本次编排，不要求不同档位统一成同一个题材。
4. 主档须已核实不少于100分钟，优先较长者；辅档已知少于30分钟的剧不排，时长未知须明确提示。没有符合档位题材和时长的剧时输出 `drama_id=null`，说明缺口，不换题材、不编造、不重复补位。
5. 覆盖全部空档位。同频道依据完整排期历史和本次结果去重，跨频道允许重复。时间由系统按档位和时区计算。只用系统提供的候选，Tempting My Keeper 永久禁用。

先生成带选剧依据、报告方向、剧情引文和编排说明的预览，用户确认后由智矩保存。此版本只处理频道分析和排期。
